# python-crypto-suite-certificats-X.509
Projet Python complet de démonstration des mécanismes cryptographiques :  🔐 Chiffrement symétrique avec AES (Fernet)  🔑 Chiffrement asymétrique avec RSA (clé publique / clé privée)  🧾 Génération de certificats X.509 auto-signés  ✍️ Signature et vérification de documents avec HMAC-SHA256
